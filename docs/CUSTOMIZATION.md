# Customization

Inject a TokenProvider to integrate your own authenticated backend. Inject HTTPTransport for deterministic tests, telemetry or a URLSession configured with your application's timeout policies. Do not log Authorization headers or token bodies.

Use SonosClient.perform with typed Endpoints for operations beyond the convenience methods. Render player capabilities before offering unsupported controls. Keep views on the main actor, catch errors into recoverable UI state and cancel view-owned tasks when leaving a screen.

The demo uses system typography, semantic colors, native lists and controls for dark mode, Dynamic Type and keyboard access. Customize its layout without coupling your business logic to SwiftUI. Test VoiceOver and accessibility text sizes on your target devices before shipping.
