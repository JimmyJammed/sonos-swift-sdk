# Sonos Swift SDK 2.0.0

Swift 6 actors and async APIs; explicit providers; SonosNetworking 2.0; Foundation/UI split; native authorization; local TypeScript token broker; fixture demos and tests; migration and validation documentation. Removes shared dependency state, Swinject, SwiftyJSON and BetterSafariView from maintained runtime. Breaking release. Publication is separate from this source change.


## Upgrade

Read [migration instructions](docs/MIGRATION.md) before replacing the previous major version. Preserve your old dependency reference if you need the historical runtime.

## Evidence and limitations

See [dated local validation](docs/VALIDATION.md). Account-free demos and local tests are included. Unavailable toolchains and live integrations are explicitly unverified. Registry publication and hosted deployment are separate actions.
